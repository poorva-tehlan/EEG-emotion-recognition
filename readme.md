## EEG Emotion Recognition

Deep learning project for classifying emotions from EEG brainwave signals.

### Models Used

- Feed Forward Neural Network
- Simple RNN

### Technologies

- TensorFlow
- Scikit-Learn
- Pandas
- NumPy
- Matplotlib

### Dataset

Kaggle EEG Brainwave Emotion Dataset
(https://www.kaggle.com/datasets/birdy654/eeg-brainwave-dataset-feeling-emotions)
